## 运行方式

本项目为纯前端单页应用，**双击 `index.html` 即可在默认浏览器中打开运行**。

技术栈为原生 HTML / CSS / JavaScript + Canvas 2D，不依赖任何第三方库、不使用 CDN、不需要 `npm install`、不需要构建打包步骤，也不需要联网。将整个文件夹拷贝到任意目录后直接用浏览器打开即可使用，推荐使用 Chrome / Edge / Firefox 等现代浏览器以获得最佳渲染效果。

## 功能清单

本模拟器实现了以下功能：

- **非线性单摆仿真**：运动方程中保留 `sinθ` 非线性项，支持初始摆角在 ±85° 范围内的大角度摆动，不做小角度线性化近似。
- **可调物理参数**：
  - 摆长 L：0.2 – 2.0 m；
  - 摆球质量 m：0.05 – 2.0 kg；
  - 重力加速度 g：1 – 25 m/s² 连续滑块，并提供地球 9.81、月球 1.62、火星 3.71 三个预设按钮；
  - 线性阻尼系数 c：0 – 0.5；
  - 初始摆角：滑块调节 ±85°，也可直接在画布上拖拽小球设定。
- **实时物理量显示**：当前角度 θ、角速度 ω、实测周期 T（当 c=0 时并列显示小角度理论周期 T₀ 作为对照）、动能 Ek、势能 Ep、机械能 E。
- **实测周期与理论周期对照**：在无阻尼（c=0）条件下，自动统计相邻两个正向摆峰（θ 同侧极大值，角速度由正变负时刻）之间的时间间隔作为实测周期，并与小角度近似公式 T₀ = 2π√(L/g) 并列显示，直观反映大角度带来的周期偏差。
- **角度-时间曲线**：以折线图绘制最近约 20 秒内 θ(t) 的变化，带网格与坐标轴刻度。
- **能量-时间三线曲线**：在同一张图上叠加 Ek、Ep、E 三条曲线，用于观察无阻尼时机械能守恒、有阻尼时机械能单调衰减的过程。
- **控制按钮**：开始 / 暂停切换、重置。
- **布局自适应**：左侧仿真画布、右侧参数与数据面板、下方图表区域，窗口尺寸变化时自动重排。

## 操作说明

### 1. 参数滑块

页面右侧参数面板中提供以下滑块，拖动即可实时改变对应物理量（仿真运行中也可调节，新参数立即作用于后续积分）：

- **摆长 L**：单位米，范围 0.2 – 2.0 m。摆长越长，周期越大。
- **质量 m**：单位千克，范围 0.05 – 2.0 kg。质量只影响动能与势能的绝对值，不影响无阻尼小角度周期。
- **重力加速度 g**：单位 m/s²，范围 1 – 25。g 越大，回复加速度越大，周期越短。
- **阻尼系数 c**：范围 0 – 0.5。c=0 为无阻尼理想摆动；c>0 时摆幅随时间衰减。
- **初始摆角**：范围 ±85°。仅在重置后生效，决定下一次摆动从哪个角度静止释放。

### 2. 重力预设按钮

参数面板上方提供三个快捷按钮：

- **地球（9.81 m/s²）**：恢复到日常重力环境。
- **月球（1.62 m/s²）**：低重力环境，摆动明显变慢。
- **火星（3.71 m/s²）**：中等偏低重力环境。

点击任一按钮会将 g 滑块同步跳到对应数值。

### 3. 拖拽小球设定初始摆角

在左侧仿真画布上，用鼠标按住摆球并拖动，即可绕悬挂点自由调整摆线方向，松开后该角度即被记为当前摆角。若此时处于暂停状态，相当于直接设定了初始释放角度；若处于运行状态，则相当于在任意时刻"抓住"小球重新释放。

### 4. 开始 / 暂停按钮

- 按钮文字为"开始"时，点击后仿真开始按 RK4 步长推进，摆球开始运动，下方曲线开始绘制。
- 按钮文字变为"暂停"时，点击后积分暂停，摆球停在当前位置，曲线停止更新。
- 再次点击"开始"从当前状态继续推进。

### 5. 重置按钮

点击"重置"后：

- 摆球回到参数面板中"初始摆角"滑块所设定的角度；
- 角速度清零，即从该角度由静止释放；
- 角度-时间曲线与能量-时间曲线的历史数据被清空，时间轴归零；
- 实测周期统计结果清零。

### 6. 图表阅读方式

- **角度-时间曲线**：横轴为时间（秒），纵轴为摆角 θ（度）。曲线与横轴的交点代表摆球经过最低点；相邻两个正向摆峰之间的时间间隔即实测周期。大角度摆动时曲线不再是标准正弦波，波峰附近会被"拉平"。
- **能量-时间三线曲线**：横轴为时间（秒），纵轴为能量（焦耳）。红色为动能 Ek，蓝色为势能 Ep，黑色为机械能 E。无阻尼时黑色线应基本水平，红色与蓝色此消彼长；有阻尼时黑色线整体单调下降。

## 物理模型与公式说明

### 1. 非线性单摆运动方程

本模拟器不做小角度线性化，直接求解有阻尼的非线性单摆方程：

$$\alpha = \frac{d^2\theta}{dt^2} = -\frac{g}{L}\sin\theta - c\,\omega, \qquad \omega = \frac{d\theta}{dt}$$

其中 θ 为摆角（相对竖直向下方向），ω 为角速度，g 为重力加速度，L 为摆长，c 为线性阻尼系数。负号表示力矩方向始终指向平衡位置。

### 2. sinθ 非线性项的物理意义

- 当摆角很小（|θ| ≪ 1 rad）时，由泰勒展开 `sinθ ≈ θ`，方程退化为线性简谐振动 `d²θ/dt² ≈ −(g/L)θ`，周期与振幅无关。
- 当摆角较大时，`sinθ < θ`，相同 θ 下的回复力矩比线性近似更小，因此**周期随振幅增大而变长**。这就是大角度单摆不再是严格等时振动的原因。

### 3. 小角度近似成立条件与理论周期

小角度近似 `sinθ ≈ θ` 通常在 **|θ| ≲ 5° – 15°**（约 0.09 – 0.26 rad）时误差可接受。此时理论周期为：

$$T_0 = 2\pi\sqrt{\frac{L}{g}}$$

本模拟器在 c=0 时会把实测周期与该 T₀ 并列显示，摆角越大，两者差值越明显。

### 4. 阻尼项 −cω

方程中的 `−cω` 是与角速度成正比的线性阻尼项，方向始终与运动方向相反，作用是把机械能通过摩擦 / 空气阻力等途径耗散为热能。c=0 时机械能守恒；c>0 时摆幅按指数趋势衰减，最终静止在最低点。

### 5. 能量表达式

以摆球最低点为势能零点：

- 动能：$$E_k = \tfrac{1}{2} m L^2 \omega^2$$
- 势能：$$E_p = m g L (1 - \cos\theta)$$
- 机械能：$$E = E_k + E_p$$

无阻尼时 E 为守恒量；有阻尼时 E 随时间单调减小。

### 6. 数值积分方法

本模拟器采用 **四阶 Runge-Kutta（RK4）** 方法对方程组 `dθ/dt = ω`、`dω/dt = −(g/L)sinθ − cω` 进行积分。外层按渲染帧率推进，内部再拆成若干固定小步长的子步逐段积分，以保证在摆长较短、g 较大或 c 较大时数值仍然稳定、不发散。

## 人机协同三反思

### 1. 人机分工回顾

本次课程作业中，我（学生）主要负责把课程作业要求拆成可验收的功能清单：明确要求保留 `sinθ` 非线性项、支持 ±85° 大角度、必须同时画出角度曲线和能量曲线、必须给出实测周期与小角度理论周期的对照，并要求在月球 / 火星重力下能看出周期变化。运行程序后，我重点检查了几个物理现象是否符合直觉：把摆长从 0.5 m 拉到 1.5 m，周期应当明显变长；切到月球预设后，同一摆长下周期应当比地球长得多；把初始摆角从 5° 调到 80°，实测周期应当比 T₀ 偏大；把 c 从 0 调到 0.2，摆幅应当一圈比一圈小。AI 则负责具体实现：搭建 HTML 页面结构、用 Canvas 绘制摆球与摆线、写 RK4 积分主循环、用 Canvas 折线图绘制两条曲线、处理鼠标拖拽小球的坐标换算。

### 2. 协作中暴露的自身短板

在这次协作中，有几处明显是 AI 代劳、我自己还没吃透：

- **非线性单摆方程的完整推导**：从切向受力分析到 `mL²·θ″ = −mgL·sinθ` 这一步，以及阻尼项为什么写成 `−c·ω` 而不是别的形式，我只是照着结论用，没有自己重新推一遍。
- **RK4 积分与稳定性条件**：为什么要在渲染帧内部再拆子步、子步长取多少才不会在短摆长 + 大 g 下发散，这些稳定性判据我没有自己分析过，直接用了 AI 给的步长。
- **Canvas 坐标系与角度方向约定**：Canvas 的 y 轴向下为正、角度逆时针为正还是顺时针为正、鼠标拖拽点到摆球角度的反算公式（atan2），这一段完全是 AI 写的，我没有独立写出过。
- **大角度周期偏离 T₀ 的物理原因**：我知道"大角度周期变长"这个结论，但对 `sinθ` 比 θ 小到底如何通过积分影响过零点时刻，还停留在定性理解，没有定量推导过周期修正项（椭圆积分 / 振幅展开）。

### 3. 下次改进计划

针对上述短板，下次做同类物理仿真作业时我打算按以下顺序改进：

1. **先补理论再动手**：正式写代码前，先把小角度近似成立条件、大角度周期的振幅展开修正项、线性阻尼的能量耗散规律自己在草稿纸上推一遍，而不是直接开 IDE。
2. **先自己写积分主循环再请 AI 评审**：RK4 的状态向量、四个 k 的计算、子步长选择，先由我自己写出第一版可运行代码，再让 AI 做 code review，而不是一开始就把积分部分整个交给 AI。
3. **先列测试用例再开发**：动手前先把验收用例写成清单——例如"c=0 时 E 曲线水平波动小于 1%"、"c=0.2 时 E 单调下降"、"θ₀=5° 时实测周期与 T₀ 偏差小于 2%"、"θ₀=80° 时实测周期比 T₀ 大 15% 以上"——每条用例跑通才算完成。
4. **坐标换算类问题先独立排查**：以后再遇到 Canvas 鼠标拖拽、坐标反算、角度方向这类几何问题，先自己在草稿纸上推一遍 atan2 与坐标系变换，卡住超过 20 分钟再向 AI 求助，避免习惯性直接索要实现。

## 进阶挑战

本作业在基础要求之上，额外实现了以下扩展功能：

- **多重力环境预设**：内置地球（9.81）、月球（1.62）、火星（3.71）三个重力按钮，一键切换即可直观对比不同天体上的摆动快慢。

- **实测周期与理论周期对照**：无阻尼时自动统计相邻正向摆峰时间间隔，并与 T₀ = 2π√(L/g) 并列显示，定量展示大角度带来的周期偏差。
